# Inclusive Cities

### Across physical and digital spaces

**Who searches, who visits?**

An interactive atlas exploring income and age segregation and mixing through online searches and offline visits in Beijing, Shanghai, Guangzhou, Shenzhen, and Chengdu.

## Explore

Choose a city, population attribute, and map view. Adjust transparency to reveal the basemap. Indicator definitions are available in **About**.

## Deployment

Keep the folder contents together, configure a public Mapbox token in `mapbox-config.js`, and enable GitHub Pages for the repository root.

Basemap: Mapbox. Third-party library licenses are included in `vendor/`.
